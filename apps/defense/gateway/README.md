# Defense gateway — flow-decision contract (issue #105)

Virtual defense gateway for the Phantom Patrol lab: deterministic
**allow / block / redirect** decisions over *simulated* flows between
virtual nodes and services. This is the policy-decision half of the
M3 interception workstream — the real lab enforcement path is #106.

## What this is / is not

- **Is:** a typed contract (`FlowTuple` → `FlowDecision`), an ordered
  rule engine with an explicit default for unmatched flows, and an
  append-only hash-chained decision log with provenance.
- **Is not:** packet interception, a firewall, or any claim of real
  network enforcement. Every decision record is stamped
  `enforcement: "simulated"`; `SimulatedEnforcementPoint` emits
  receipts showing what a future enforcer *would* do — it opens no
  sockets and installs no rules.

## Contract (schema_version 1)

`FlowTuple`: `flow_id`, `src`/`dst` (`node_id` + `service`),
`provenance` (`DEMO|REPLAY|LIVE` — required, honest labeling).

`FlowDecision`: `decision_id`, the flow, `decision`
(`allow|block|redirect`), `reason`, `policy_id` + `policy_version`,
`rule_id` (`null` = produced by the default path), `redirect_to`,
`ttl_s`, `decided_at` (UTC), `trace_id`, `provenance`,
`enforcement="simulated"`, `engine`, `content_hash` (deterministic
sha256 over contract fields — correlation key for #106/#108).

`FlowPolicy`: ordered `rules` (first match wins), explicit
`default_action` — `deny` (fail-closed → unmatched flows block) or
`monitor` (fail-open → unmatched flows allow, still logged with
`rule_id=null`). There is no implicit default; the choice is part of
the policy and is tested.

See `docs/04-DATA-AND-INTERFACES.md` → "Flow-decision contract" for
the canonical schema doc.

## Usage

```python
from defense_gateway import (
    DecisionEngine, DecisionLog, DefaultAction,
    FlowDecisionKind, FlowEndpoint, FlowMatch,
    FlowPolicy, FlowRule, FlowTuple, Provenance,
    SimulatedEnforcementPoint,
)

policy = FlowPolicy(
    policy_id="pol-edge-01",
    rules=[FlowRule("allow-lab", FlowMatch(dst_service="http"),
                     FlowDecisionKind.ALLOW)],
    default_action=DefaultAction.DENY,
)
engine = DecisionEngine(policy)
log = DecisionLog("decisions.jsonl")

flow = FlowTuple(flow_id="flow-001",
                 src=FlowEndpoint("lab-client-01", "https"),
                 dst=FlowEndpoint("dc-pi-02", "http"),
                 provenance=Provenance.DEMO)
d = engine.evaluate(flow, trace_id="trace-1")
log.append(d)                       # hash-chained, verifiable
SimulatedEnforcementPoint().apply(d)  # simulated receipt only
```

Malformed flows (bad ids, invalid service names, bad provenance,
oversized fields) raise `FlowValidationError` — never silently
coerced.
